Legend

  • Solid box and arrow: exists today (roster and routines, 2026-10-12).
  • Dashed teal: proposed, nothing built, nothing created.
  • Owner approval points: every brief to the orchestrator needs the owner's go (PPT sends it signed); literature review batches go to the owner by email before anything is approved; the proposed data agent would be read-only until the owner says otherwise.
  • Who can write where: coding specialist writes branches and pull requests in product repos and its report; task agent and reviewer write only in ppt-knowledge; CRM agent writes drafts and HubSpot notes only; literature agent and reviewer write only their files in ppt-knowledge. Eval agent: reads ppt-knowledge and the production database, writes only evals/ and literature/gaps.md plus tables starting aieval_. Nobody except PPT emails the owner, and no agent publishes or contacts outsiders on its own.
  • Not drawn, to keep it readable: the session librarian reads the owner's business sessions; the manager and CRM agent read the owner's Gmail; the data agent would also read HubSpot totals through the CRM agent's log.
